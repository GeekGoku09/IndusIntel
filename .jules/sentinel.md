## 2025-05-22 - Defensive Input Validation on Express Request Arrays
**Vulnerability:** In Express request handlers (such as `/api/copilot-chat`), relying on default parameter destructuring like `{ messages = [] } = req.body` fails when the client explicitly passes `messages: null` or a non-array value. Subsequent operations like `messages.length` or iterating array elements threw unhandled `TypeError` exceptions outside of try/catch blocks, abruptly terminating the entire Node.js server process (Denial of Service).
**Learning:** Default destructuring in JavaScript only applies when the key is `undefined`, not when it is `null`, a primitive string, or other types. Without explicit type checks and route-level try/catch blocks, malformed POST payloads can trivially crash the application process.
**Prevention:** Always validate array payloads with `Array.isArray()` (or a schema validator) before property accesses or loops, sanitize individual item shapes, and wrap async route handlers in top-level try/catch blocks returning safe 400 or 500 error responses without exposing server stack traces.
