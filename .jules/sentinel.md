## 2026-11-02 - XML Injection and CSV Formula Injection in Syndication Exporters
**Vulnerability:** Client-side BMEcat 2005 XML export in `SyndicationExporter.tsx` was directly interpolating unescaped product strings into XML tags, allowing XML markup corruption / XML injection. Concurrently, both client and server CSV exports wrapped fields in quotes but did not neutralize spreadsheet formula characters (`=`, `+`, `-`, `@`, `\t`, `\r`), posing CSV formula injection risks (CWE-1236) when imported into spreadsheet programs like Excel or Calc.
**Learning:** Export pipelines that generate XML or CSV from user-provided or OCR-extracted catalog data must not rely on simple string templating or basic quoting. XML elements require character entity escaping (`<`, `>`, `&`, `'`, `"`), and CSV cells must prepend `'` to strings starting with formula trigger characters to prevent command execution and spreadsheet formula evaluation.
**Prevention:** Always sanitize cells through `escapeXml` for XML exports and `sanitizeCsvCell` for CSV exports across both client and server syndication endpoints.
